# Quick start

1. Load the extracted extension folder from Dia's chrome://extensions page.
2. Open Extensions → QuickCurrency and enter USD 100.
3. Choose a target and convert. Highlighting a price before opening the popup pre-fills it.
4. Enable automatic highlighting per website from the popup if desired.
5. Use the gear button for defaults, number formats, favourites and proxy settings.

See README.md for updating an unpacked install and rate limitations.
