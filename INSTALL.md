# Installation

Follow the [current install and update guide](README.md#install-in-dia). The extension is loaded unpacked from a permanent folder containing manifest.json. Extract release ZIPs before loading them.

Dia was the development target for 1.2.0. Other Chromium browsers implementing the declared APIs may work, but automated JavaScript checks do not certify another browser. Firefox and Safari packages are outside this release.

Proxy configuration and website permissions are explained in the [README](README.md). No server is needed for normal use.
